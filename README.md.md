## Sobre o Projeto

O **RentSmart** é um sistema desenvolvido em Python com Programação Orientada a Objetos (POO) para automatizar os orçamentos de locação da **R.M Imóveis**. Ele aplica as regras de apartamentos, casas e estúdios, calcula adicionais e descontos, separa a taxa contratual do aluguel mensal e gera uma projeção de 12 meses em arquivo `.csv`.

## Arquivos do Projeto

* `rentsmart.py`: Código-fonte principal com as classes (`Imovel`, `Apartamento`, `Casa`, `Estudio`, `OrcamentoLocacao` e `GeradorCSV`), validação de entradas e interface no terminal.

* `exemplo_projecao_12_meses.csv`: Exemplo de projeção anual gerado pela aplicação.

* `README.md`: Instruções de execução e informações do projeto.

## Como Executar

1. Certifique-se de ter o **Python 3.10+** instalado (não é necessária nenhuma biblioteca externa).

2. Abra a pasta do projeto no **VS Code** ou no terminal.

3. Execute o comando:

   ```
   python rentsmart.py
   
   ```

4. Responda às perguntas exibidas no terminal para visualizar o resumo do orçamento e salvar o arquivo `.csv` com a projeção de 12 meses.
